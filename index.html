Anleitung

Zuerst oben auf „Signatur kopieren“ klicken, dann im Mailprogramm einfügen (Cmd/Strg + V).

Gmail

  1. Zahnrad oben rechts → Alle Einstellungen aufrufen
  2. Tab Allgemein → Abschnitt Signatur → Neu erstellen
  3. In das Textfeld einfügen, ganz unten Änderungen speichern

Outlook (Web & neues Outlook)

  1. Zahnrad → Konten → Signaturen
  2. Neue Signatur anlegen, einfügen, als Standard für neue Nachrichten/Antworten wählen, Speichern

Outlook Desktop (klassisch)

  1. Datei → Optionen → E-Mail → Signaturen…
  2. Neu, Namen vergeben, in das Bearbeitungsfeld einfügen, OK

Apple Mail

  1. Mail → Einstellungen → Signaturen → Account wählen → +
  2. Häkchen bei „Immer meiner Standardschrift entsprechen“ entfernen
  3. Vorschau-Text rechts löschen und die Signatur einfügen
